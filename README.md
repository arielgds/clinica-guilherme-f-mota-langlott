# 🩺 Landing Page - Clínica Dr. Guilherme F. Mota Langlott

Projeto desenvolvido como parte das atividades de extensão universitária (PEX), unindo conceitos de desenvolvimento web front-end, UX, SEO local e LGPD aplicados à área da saúde.

## 🚀 Tecnologias Utilizadas
* HTML5 Semântico
* CSS3 (Mobile-First, Flexbox e Grid)
* Vanilla JavaScript (Interatividade, Modal Exit-Intent, Accordion e Validações)

## 📍 Sobre o Projeto
Plataforma web desenvolvida para a Clínica Guilherme F. Mota Langlott (Itamonte - MG), com foco em conversão de pacientes, triagem rápida via WhatsApp e integração com convênios e parceiros (Unimed, Bradesco Saúde, SulAmérica, ACIPAQ, iconsorcio e erpmed).
